# Разделение состояния

- **Предложение**: Разделить управление состоянием на уровне приложения, используя глобальные сигналы для активной вкладки и языковой пары. Это позволит избежать передачи состояния через_props_и упростит управление.
- **Обоснование**: Глобальные сигналы обеспечивают единое управление состоянием, что улучшает поддерживаемость кода и предотвращает дублирование логики.

# Ленивая загрузка вкладок

- **Предложение**: Использовать LoadChildren для ленивой загрузки вкладок, чтобы снизить нагрузку на первый загрузочный цикл.
- **Обоснование**: Ленивая загрузка уменьшает размер инициальной загрузки приложения, улучшая производительность.
