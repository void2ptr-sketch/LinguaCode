# Goal: Keep the app accessible — follow the established ARIA and keyboard patterns.

## Established project patterns (follow them)

- **Semantic landmarks**: `<nav aria-label="…">`, `<section aria-label="…">` / `aria-labelledby`, `<aside aria-label="…">`.
- **Icon buttons**: `mat-icon` with `aria-hidden="true"` + `aria-label` on the button (e.g., `aria-label="Удалить"`, `aria-label="Редактировать"`).
- **Decorative images**: `alt=""` + `aria-hidden="true"`.
- **Toggle state**: `[attr.aria-pressed]` for toggle buttons, `[attr.aria-selected]` for tabs/tree items, `[attr.aria-disabled]` for disabled interactive nodes.
- **Live regions**: `role="status"` for non-critical updates, `role="alert"` for errors, `aria-live="polite"` for async loading overlays.
- **Groups & structure**: `role="group"` / `role="tree"` + `treeitem` / `role="grid"` + `row`/`rowheader`/`columnheader`/`gridcell` / `role="tablist"` + `tab` / `role="toolbar"` — as used in journey map, display matrix, draw card.
- **Hints**: `aria-describedby` pointing to a hint element (`id`).
- **Keyboard**: handle `Escape` via `@HostListener('document:keydown.escape')` (see `card-focus-shell`); manage `tabindex` for conditionally visible controls (see `pinyin-keyboard`: `[attr.tabindex]="showToneRow() ? 0 : -1"`).

## Rules

- **Every interactive element must be keyboard-accessible** and have an accessible name (`aria-label`, text content, or `matTooltip` + `aria-label`).
- **Do not rely on color alone** to convey state (e.g., locked/favorite) — add text or ARIA state.
- **Loading/empty/error states** must be announced: `aria-label` on loading placeholders, `role="status"`/`role="alert"` for results.
- **Focus management**: when opening/closing overlays, dialogs, or fullscreen modes, move focus appropriately and restore it on close (Angular Material handles this for `MatDialog`/`MatMenu`).
- **Do not remove focus outlines** (`:focus-visible`) — keep visible focus indicators.
- **Test a11y**: include assertions for `aria-label`/`role` in component specs (existing pattern: `expect(navList?.getAttribute('aria-label')).toBe('Навигация')`).
