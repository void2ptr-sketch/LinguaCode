# Goal: Keep `.continue/rules/` accurate, non-duplicated, and the single source of truth for AI behavior.

## Single source of truth

- `.continue/rules/` (CONTINUE.md + rules 00–40) is the **authoritative** instruction set for AI assistants.
- Parallel instruction files (`KODA.md`, `.cursorrules`, etc.) must either point here or stay in sync. When they drift, fix them or remove the duplicated content — do not leave contradictions.
- `CONTINUE.md` is the project guide and rule index; individual rules hold the details. Avoid duplicating the same fact in both (duplication is the main drift risk — e.g. coverage thresholds existed in 3 places).

## Verify rule claims against actual config

Before relying on or writing a rule that states a number/command/flag, check the real source:

| Rule claim | Source of truth |
| ---------- | --------------- |
| Coverage thresholds | `angular.json` → `coverageThresholds` |
| npm scripts & verify pipeline | `package.json` → `scripts` |
| TS strictness / paths | `tsconfig.json` |
| CI steps | `.github/workflows/ci.yml` |
| API contract | `docs/API-CONTRACT.md` |
| Content/data layout | `docs/SYSTEM/MOCK-DATA.md`, `content-manifest.json` |

If a config changes and a rule becomes stale, **update the rule in the same change** (this is what rule 40 is for).

## Adding/editing rules

- Number sequentially: next free number after 40 (no duplicate numbers — see historical duplicate `00` issue).
- Every rule has front-matter: `description` + `globs` (scope) or `alwaysApply: true` for global rules.
- Keep rules concise (aim ≲ 60 lines), actionable, and cross-linked to related rules/docs instead of restating them.
- When adding a rule, add its reference to `CONTINUE.md` §8.

## Naming

- Meta/agent-behavior rule: `00.agent-behavior.rule.md`. Angular-specific: `NN.angular.<topic>.rule.md`. Cross-cutting: `NN.testing.*` / `NN.<topic>.rule.md`. The `NN.` prefix orders application of related rules.

## Housekeeping

- Periodically (or when touching configs) run a consistency scan: cross-check numbers in rules vs. config files, verify referenced file paths exist, and verify referenced npm commands exist in `package.json`.
- Empty scaffolding dirs (`.continue/agents/`, `.continue/prompts/`, `.continue/mcpServers/`) are either filled with content or removed — do not commit empty placeholders.
