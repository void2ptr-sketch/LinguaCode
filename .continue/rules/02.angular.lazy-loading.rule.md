# Goal: Enforce proper lazy loading with standalone routing.

# For routing:
- Implement lazy loading via `loadComponent` in `app.routes.ts` — this is the project pattern.
- Never use `loadChildren`/NgModule-based lazy loading or Module Federation: the project does not use them.
- Each feature page is a standalone component imported lazily:

  ```typescript
  {
    path: 'cards/select',
    loadComponent: () =>
      import('./features/card-select/components/card-select-page/card-select-page.component').then(
        (m) => m.CardSelectPageComponent,
      ),
  }
  ```

- Prefer route-level lazy loading over eager imports of feature code; keep shared UI in `shared/` (eager).
