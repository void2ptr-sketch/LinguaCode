# Goal: Drive modern Angular architecture instead of falling back to NgModules and BehaviorSubject by default.

# When generating or refactoring Angular code:
- Use standalone components exclusively (no NgModules); see `angular.project-architecture.rule.md`.
- Prefer Signals (`signal`, `computed`, `effect`) over RxJS subjects for local state management.
- Use `toSignal` / `toObservable` only when interoperability with existing RxJS streams is required.
- Avoid `async` pipe with manual subscriptions unless it’s a complex observable chain that benefits from explicit control.
- Detailed reactive patterns live in `05.angular.Reactive.rule.md`; DI and provider rules in `04.angular.DI-PS.rule.md`.
