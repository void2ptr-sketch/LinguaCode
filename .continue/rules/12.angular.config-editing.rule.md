# Goal: keep build/test configs valid and minimal during edits.

# When editing configuration files (angular.json, tsconfig.json, package.json, proxy.conf.json, vitest.config.ts):
- Change only the sections required by the task; do not touch unrelated parts.
- Keep comments and formatting; preserve JSON/JSONC structure and indentation.
- Validate keys, nesting, and value types after every edit.
- Verify changes with:
  - `npm run lint` 
  - `npm run build`
  - `npm run test`
  - `npm run audit:fsd`
  - `npm run check:imports`
  - `npm run audit:barrels`
