# Goal: Encourage modern DI patterns and prevent provider duplication.

# For DI and providers:
- Use `providedIn: 'root'` for singleton services; avoid adding services to `providers` arrays unless scoping is intentional.
- For feature-scoped providers, use `provide: MyService` in `providers` of standalone components or route guards.
- When refactoring, detect and remove redundant providers that cause multiple instances.
- Prefer injection tokens for configuration objects instead of hard-coded values.
- `providedIn: 'root'` makes services tree-shakable and easy to mock in tests.
