# Goal: Ensure testability and coverage aligned with Angular best practices.

# Testing rules:
- Generate unit tests using Vitest with meaningful assertions.
- Mock external dependencies (services, APIs) instead of calling real endpoints.
- Include tests for:
  - Component initialization and input/output bindings.
  - Reactive streams (observables, signals).
  - Error handling and edge cases.
- Avoid writing tests that rely on global state or uncontrolled async behavior.

# Coverage thresholds (configured in angular.json, `coverage` configuration — source of truth):
- statements 70%, branches 65%, functions 70%, lines 70%.
- Run coverage locally: `npm run test:coverage` (coverage includes `src/app/**/*.ts`, excludes `*.spec.ts` and mocks).
- New features must not lower coverage below the thresholds.
- If `angular.json` (`coverageThresholds`) changes, update this section — rule values must match the actual config (see `40.rules-maintenance.rule.md`).
