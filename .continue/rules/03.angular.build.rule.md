# Goal: Leverage Ivy features and avoid legacy patterns.

# Regarding builds and compilation:
- Assume Ivy is enabled; do not suggest ViewEngine‑specific workarounds.
- For performance:
  - Use `defer` blocks for non‑critical components.
  - Apply `NgOptimizedImage` directive for images.
  - Minimize inline styles; prefer CSS files or component‑scoped styles.
- Avoid suggesting `encapsulation: ViewEncapsulation.None` unless there’s a documented need.
