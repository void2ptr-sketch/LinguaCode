# Goal: Never call the write tool without a full file path and full content.

# When writing files:
- Always provide the **full path** to the target file (relative to the project root).
- Always provide the **complete content** of the file — no placeholders, no partial updates, no "rest of code unchanged".
- If the file already exists and only a small change is needed, prefer targeted edits (search/replace) over a full rewrite.
- If the path or content is missing or empty, do not call the write tool — state what is missing and ask for the required information.

# Validation checklist before calling write:
- [ ] `filePath` is defined and non-empty
- [ ] `content` is defined and non-empty
- [ ] `content` contains the complete intended file (for new files) or the complete updated file (for rewrites)
- [ ] The path is inside the allowed project scope (see `01.meta.01.agent-behavior.rule.md`)
