# Goal: Maintain high type safety and avoid any.

# TypeScript expectations:
- Never use `any`; prefer explicit types or `unknown` with proper narrowing.
- Leverage utility types (`Partial`, `Pick`, `Omit`) when appropriate.
- Use generics for reusable components/services.
- Enable and respect `strict` mode settings; do not suggest disabling strict checks.
- Prefer `type` aliases over `interface` for data structures and models (project convention); use `interface` mainly for class contracts when required.
