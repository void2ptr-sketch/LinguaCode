# Goal: Ensure every change is verified before the task is considered done.

Run the full pipeline before finishing any task that touches code, config, or content:

```bash
npm run verify
```

`npm run verify` = lint + audit:fsd + check:imports + audit:barrels + sync:hanzi + build:prod + test:ci.

## Full checklist (run relevant parts)

| Check | Command | When |
| ----- | ------- | ---- |
| Lint | `npm run lint` | always (code changes) |
| Format | `npm run format` | always (code/docs changes); `npm run format:fix` to write |
| FSD layers | `npm run audit:fsd` | always (src/app changes) |
| Import resolution | `npm run check:imports` | after moving/renaming files |
| Barrel exports | `npm run audit:barrels` | after adding/removing `index.ts` or exports |
| Hanzi assets | `npm run sync:hanzi` | after content/card changes |
| Build | `npm run build` / `npm run build:prod` | always (code changes) |
| Unit tests | `npm run test:ci` | always (code changes) |
| Coverage | `npm run test:coverage` | for new features — thresholds: statements 70%, branches 65%, functions 70%, lines 70% |
| Security audit | `npm run audit` | after dependency changes |

## Rules

- **Exit code 0 = clean.** Fix all violations before finishing; do not leave failing checks.
- Run `npm run verify` at minimum — it covers the critical path (lint, FSD, imports, barrels, hanzi sync, production build, CI tests).
- For config file edits, also follow `03.angular.08.config-editing.rule.md`.
- For content/data edits, also follow `05.business.02.data-content.rule.md`.
