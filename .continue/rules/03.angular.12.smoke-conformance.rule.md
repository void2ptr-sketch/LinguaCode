# Goal: Keep route smoke tests and API conformance tests consistent and green.

## Smoke tests (`*.smoke.spec.ts`)

- Location: `src/app/app/*.smoke.spec.ts` — one per feature/route (`app.smoke.spec.ts`, `card-select.smoke.spec.ts`, `card-editor.smoke.spec.ts`, `course-builder.smoke.spec.ts`, `home-learning.smoke.spec.ts`, `journey.smoke.spec.ts`).
- Purpose: verify the route **renders** when navigated (lazy chunk loads, no runtime errors, key content appears).
- Setup:
  - `TestBed.configureTestingModule` with `provideHttpClientTesting()`; mock API responses via `HttpTestingController` — smoke tests must **never** hit real endpoints.
  - Configure the router: `provideRouter(routes)` + `provideLocationMocks()`; navigate with `await router.navigateByUrl('/<path>')`.
- Assert: route resolved, component rendered, no error toast, expected landmarks/text present.
- A smoke test must exist for every feature page added to `app.routes.ts` (see `02.architecture.05.routing.rule.md`).

## API conformance tests (`*.conformance.spec.ts`)

- Purpose: verify services/ports/mocks **mirror the API contract** from `docs/API-CONTRACT.md` (URLs, wrappers `ApiResponse`/`ApiListResponse`, error body `{ message, code, details }`).
- Run in CI separately (see `01.meta.07.ci-parity.rule.md`):
  ```bash
  npx ng test --no-watch --no-progress --include='**/*.conformance.spec.ts'
  ```
- When a contract endpoint changes (see `05.business.05.env-api-contract.rule.md`), update: API service, port, mock interceptor, **and** the conformance tests.
