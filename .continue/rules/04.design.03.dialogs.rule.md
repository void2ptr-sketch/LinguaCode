# Goal: Follow the established modal dialog pattern (`docs/PATTERNS/MODAL-DIALOG.md`).

## Component + Service pair

- Each dialog = a **dialog component** + a **companion `*DialogService`** that owns `MatDialog.open(...)` and result typing:

  `card-editor-dialog.component.ts` + `card-editor-dialog.service.ts`, `course-builder-dialog`, `scenario-builder-dialog`, `card-try-dialog`.

## Mandatory patterns

- Inject:
  - `readonly data = inject<DialogData>(MAT_DIALOG_DATA);`
  - `readonly dialogRef = inject<MatDialogRef<Component, Result>>(MatDialogRef);`
- **Typed results**: the dialog returns `void` or a typed result interface; the service exposes `open(...): Observable<Result | undefined>`.
- Close actions: `dialogRef.close(result)` on submit; `close()` / `cancel()` on cancel; confirm discarding changes (see discard-dialog pattern below).
- `@if (store.loading())` loading state and `@if (store.error())` error block inside `mat-dialog-content` (project pattern).
- Buttons live in `mat-dialog-actions align="end"`; primary action disabled until valid/dirty.

## Discard confirmation

- If the dialog edits data, guard cancel with a confirm discard dialog (see `features/card-editor/components/card-form-tabs/card-form-tabs.component.ts` + `shared/ui/dialogs/card-editor-discard-dialog.component.ts`). Do not silently lose edits (see `03.angular.11.forms.rule.md`).

## a11y

- `MatDialog`/`MatMenu` handle focus trapping and restore; do not implement custom focus logic. Provide `aria-label` on dialog content when needed (see `04.design.02.a11y.rule.md`).
