# Goal: Prevent common security pitfalls.

# Security rules:
- Sanitize user input when rendering HTML; never bind directly to `[innerHTML]` without sanitization.
- Validate and sanitize URLs before using them in redirects or dynamic imports.
- Avoid storing sensitive data in localStorage unless encrypted and justified.
- Use Angular’s built‑in security mechanisms (DOM sanitization, XSS protection) instead of custom solutions.
