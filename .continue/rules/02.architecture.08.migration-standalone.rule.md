# Goal: Migrate legacy NgModule code to standalone safely, keeping tests green.

# Migration rules:
- Use the official migration schematics: `ng generate @angular/core:standalone` (components, directives, pipes, and `standalone-bootstrap` steps).
- Convert routes from NgModule lazy loading (`loadChildren` + `NgModule`) to standalone `loadComponent`.
- Replace `BrowserModule`/`CommonModule` imports in migrated classes with the `imports` array of the standalone component.
- Move root providers to `app.config.ts` (`provideHttpClient()`, interceptors, etc.) instead of `AppModule`.
- Delete empty NgModules after migration; verify with `ng build` and the Vitest suite (`ng test --configuration=ci`).
- When suggesting changes across Angular versions, flag breaking changes explicitly and provide a step-by-step migration path.
- Reference: https://angular.dev/reference/migrations/standalone
