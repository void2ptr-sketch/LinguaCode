# Goal: Keep environment config and the API contract consistent.

## Environment files

- Types: `src/environments/environment.types.ts` (`Environment` type) — single source of truth for the shape.
- Values: `src/environments/environment.ts` (dev) and `src/environments/environment.production.ts` (prod).
- **Both files must implement the same `Environment` type** — adding/removing a field requires updating the type and both files.
- Mock flags (`useCardsApiMock`, `useScenariosApiMock`, `useCoursesApiMock`) are `true` in dev, `false` in production. `authEnabled` controls the real auth flow (token/refresh).
- Do not hard-code environment values in components/services — inject `environment` or use the shared API helpers.

## API contract

Full source of truth: `docs/API-CONTRACT.md`.

- Base URL: `buildApiUrl(path)` → `${environment.apiUrl}/${environment.apiVersion}${path}` (e.g., `/api/v1/...`). Version comes from `environment.apiVersion`.
- Response wrappers: `ApiResponse<T>` → `{ "data": T }`; list responses `ApiListResponse<T>` → `{ "data": T[], "total": number }` (types in `src/app/shared/api/api.types.ts`).
- Errors: HTTP status + body `{ "message": string, "code"?: string, "details"?: unknown }`.
- Auth: `Authorization: Bearer <accessToken>` (see `authInterceptor` + `AuthTokenStorage`).

## Layering (project pattern)

- API services: `src/app/entities/<slice>/api/*.service.ts` (e.g., `CardsApiService`).
- Ports (interfaces for repositories): `src/app/entities/<slice>/repository/*.port.ts`.
- Mock interceptors: `src/app/entities/<slice>/api/mock/*.mock.interceptor.ts` — mirror the real API contract exactly.
- URL helpers: `src/app/shared/api/api-url.ts`; shared types: `src/app/shared/api/api.types.ts`.

## Rules

- **When changing an API endpoint, update `docs/API-CONTRACT.md`** — the contract must stay in sync with services, ports, and mocks.
- New endpoints must be added to: the API service, the port, the mock interceptor (if mocked), and the contract doc.
- Do not bypass the wrapper types (`ApiResponse`/`ApiListResponse`) — parse responses through them.
- Do not change `apiVersion` without a migration plan for existing endpoints.
