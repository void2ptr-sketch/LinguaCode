# Улучшение вопросов в C++ карточках LinguaCode

## 📊 Итоги улучшения (3-й этап — ручная курация банков)

### Что было сделано

Обнаружено, что предыдущий «скриптовый» этап оставил 145 сценариев с полностью
шаблонными и бессодержательными вопросами (одна и та же заготовка на все темы,
вопрос повторялся в качестве единственного «правильного» варианта, дистракторы
вида «Не имеет отношения к C++», «Устаревшая технология», «Только для embedded»,
«Применяется только в теории»).

Были **вручную составлены банки качественных вопросов по теме каждого сценария**,
а затем заменён только контент карточек — **без удаления карточек**: сохранены
`id`, `appearance`, `direction`, `courseId`, `lessonId`, `scenarioId`
и измерение `meta.knownLanguage`/`meta.learningLanguage`.

### Статистика

- **Заменено файлов карточек**: 145
- **Заменено вопросов**: 2 900 (по 20 на сценарий)
- **Осталось «плохих» карточек**: 0
- **Файлов без изменений**: 209 (уже были корректными)
- **Дубликатов id**: 0
- **Нерабочих ссылок в сценариях**: 0
- **Исправлено несоответствие id**: файл `cpp.basics.vectors.01.cards.json`
  использовал некорректный префикс `scenario-cpp-basics-vectors-01` —
  приведено к каноническому `cpp.basics.vectors.01.scenario.*`.

### Инструменты

- [`scripts/fix-cpp-card-questions.py`](../../scripts/fix-cpp-card-questions.py) —
  детекция «плохих» карточек + замена контента из банков, сохраняя структуру.
- `scripts/cpp-question-banks/*.json` — 20 банков, покрывающие все 145 сценариев:
  - basics (59 тем + 20 дублей `performance` через `aliases`)
  - oop (15 тем: fundamentals/inheritance/polymorphism)
  - stl (10 тем: containers/algorithms)
  - advanced (42 темы: memory, modern, concurrency, systems, apps, engineering)

### Критерии качества новых вопросов

- ✅ Вопрос проверяет понимание, а не запоминание (edge cases, UB, lifetime,
  move-семантика, сложность алгоритмов).
- ✅ Дистракторы правдоподобны и отражают типичные ошибки.
- ✅ Только один правильный ответ (`correctIndex`).
- ✅ Контент соответствует теме урока и сценария (по `scenarioId`).
- ✅ Для C++-тем активно используются `code-trace` (предсказание вывода).
- ✅ `meta.tags` использует существующие теги курса.
- ✅ Вопросы написаны на русском (RU → C++).

### Верификация

Проверочный скрипт подтверждает:

- Все 354 файла карточек валидны (JSON).
- Во всех карточках курса 0 шаблонных дистракторов и 0 повторений вопроса
  в качестве варианта.
- Уникальность id во всём курсе.
- Все ссылки `scenario.cardSource.cardIds` разрешаются.
- Манифест `public/data/content-manifest.json` не менялся (файлы не удалялись
  и не добавлялись).
