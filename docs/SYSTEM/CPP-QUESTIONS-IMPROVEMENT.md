## 🔧 Методология улучшения

### Подход
1. **Анализ темы**: Определение ключевых аспектов каждой темы
2. **Генерация вопроса**: Создание конкретного, обучающего вопроса
3. **Варианты ответов**: Добавление релевантных дистракторов
4. **Детерминизм**: Использование хеша темы для выбора вопроса (одинаковый вопрос для одинаковой темы)

### Критерии качества
- ✅ Вопрос должен быть конкретным и понятным
- ✅ Вопрос должен проверять знание, а не просто факт
- ✅ Варианты ответов должны быть релевантными
- ✅ Правильный ответ всегда на первой позиции (correctIndex: 0)
