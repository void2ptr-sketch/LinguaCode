# Editor UX (G12)

Цель: упростить создание и редактирование карточек. Базовый сценарий — select ru→en за **≤ 8 полей** и **< 2 мин**.

Связанные документы: [INDEX.md](./INDEX.md) · [ARCHITECTURE.md](../PRODUCT/ARCHITECTURE.md) · [TASKS.md](../TASKS.md).

## Режимы

| Режим           | Переключатель                | Видимые вкладки                                                   |
| --------------- | ---------------------------- | ----------------------------------------------------------------- |
| **Базовый**     | «Расширенный режим» выключен | Содержание, Ответы, Размещение                                    |
| **Расширенный** | «Расширенный режим» включён  | Содержание, Ответы, Оформление, Размещение, Публикация            |

- Переключатель «Расширенный режим» находится в шапке диалога редактора.
- Выбор сохраняется в `sessionStorage` (`lingua-code.card-editor.ux-mode`) через
  `saveEditorUxMode` и восстанавливается при следующем открытии диалога.
- Вкладка «Ответы» скрыта для flip-карточек: у них нет объективного ответа.
- «Размещение» остаётся видимой в базовом режиме: карточки, созданные из каталога,
  всё ещё нужно привязать к курсу/программе/уроку.
- Если после смены режима активная вкладка стала скрытой, форма возвращается
  на «Содержание».

## Вкладки редактора

| Вкладка     | Поля                                                                                                                                                                                                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Содержание  | Название; вопрос/контекст/подсказка (known); код вопроса для `code-select`/`code-trace`; caption/question; слог без тона для `tone`; ориентир для `draw`; стороны `flip`; свёрнутая секция лексемы подсказки и audio URL |
| Ответы      | Kind-specific редактор ответов: варианты и правильный ответ для choice/code-select, пары `memory`, метка и варианты `sound`, принятые ответы `keyboard`, режимы `draw`; лимит времени `timed`; режим ответа `keyboard` |
| Оформление  | Тема и размер шрифта                                                                                                                                                                                                    |
| Размещение  | Курс → программа → урок → сценарий                                                                                                                                                                                      |
| Публикация  | Сложность, теги, уровень доступа, публикация; свёрнутая техническая read-only секция (`slug`, `languagePairId`, `updatedAt`, `order`)                                                                                  |

Языковая пара показывается в шапке диалога как read-only summary, а не во вкладке.

Комбо «Курс» на вкладке «Размещение» загружает **все** курсы (`scope: 'all'`)
независимо от активной языковой пары — так же, как конструкторы сценариев,
программ и уроков. Фильтрация по паре оставляла в списке только курс текущей
пары (например, `C++ Complete Course`).

### Бейджи валидации

- Счётчики ошибок на вкладках вычисляет `cardDraftTabIssues` в
  `utils/validation/card-validation.utils.ts`; он использует те же санитайзеры и
  правила, что и `normalizeCardDraft`, поэтому бейджи не расходятся с сохранением.
- «Содержание»: отсутствует название или обязательное поле вопроса.
- «Ответы»: отсутствуют/некорректны варианты, правильный ответ, принятые ответы
  или другие обязательные данные ответа.
- «Оформление», «Размещение», «Публикация» не имеют блокирующих правил и бейджей
  не получают.
- Бейдж доступен скринридеру как «Ответы, 2 ошибки» (правильная русская форма
  единственного/множественного числа).

## Создание карточки

### Меню (4 группы вместо 10 kind'ов)

1. **Выбор** — select, timed, reading, symbol, tone
2. **Ввод** — keyboard, draw
3. **Пары** — memory
4. **Медиа** — sound

### Wizard (базовый режим, только create)

- `CardCreateWizardComponent` и вычисляемый `showWizard` остаются точкой расширения.
- В текущем диалоге wizard не подключается: create сразу открывает форму карточки
  (в базовом режиме — три вкладки, в расширенном — пять). Это осознанное состояние
  до отдельной задачи по подключению wizard.

## Упрощение домена (G12c)

### reading

- В JSON остаётся `kind: 'reading'` (legacy совместимость).
- В каталоге — теги `reading`, `polyphony`.
- Целевое состояние: `select` + meta-тег `reading`.

### tone

- В JSON остаётся `kind: 'tone'`.
- Варианты тонов **автогенерируются** из `syllableBase` (mā · má · mǎ · mà).
- Целевое состояние: `select` с автозаполненными вариантами.

### Lexeme-first

При сохранении:

- `optionsLearning[i]` ← `optionsLexemes[i].primary` (если задана)
- Аналогично для `symbols`, `optionsKnown`, `audioLabelLearning`, пар memory

Legacy JSON с расхождением текст/лексема: при load текст сохраняется; при save побеждает лексема.

## Каталог карточек `/tools/cards`

> **Статус:** готово. Страница каталога карточек, открытая из sidebar «Инструменты → Каталог карточек».

### Архитектура

```
CardEditorPageComponent
├── CardCatalogSearchStore (поиск + пагинация)
├── Фильтры (known/learning language, kind, tags)
└── CardListComponent
    ├── Пагинация
    └── CardIndexEntry items
```

### Компоненты

| Компонент                 | Назначение                                |
| ------------------------- | ----------------------------------------- |
| `CardEditorPageComponent` | Страница каталога: поиск, фильтры, список |
| `CardEditorDialogService` | Открытие dialog create/edit/view          |
| `CardEditorStore`         | CRUD карточек, delete, error state        |

### Фильтры

| Фильтр             | Тип               | Описание                      |
| ------------------ | ----------------- | ----------------------------- |
| `knownLanguage`    | `ContentLanguage` | Язык known (locked при G8)    |
| `learningLanguage` | `ContentLanguage` | Язык learning (locked при G8) |
| `kind`             | `CardKind[]`      | Тип карточки                  |
| `tags`             | `string[]`        | Теги карточки                 |
| `query`            | `string`          | Текстовый поиск               |

### Locked language pair (G8)

При активном `LanguagePair` фильтры `knownLanguage` / `learningLanguage` заблокированы:

- Подпись **«Курс: …»** в шапке фильтров
- Hint: «Сменить курс — в Профиле»
- `clearFilters()` не сбрасывает known/learning

### Диалог редактора

| Режим        | Заголовок           | Save | Discard confirm |
| ------------ | ------------------- | ---- | --------------- |
| create       | «Новая карточка»    | да   | при dirty draft |
| edit (свой)  | «Редактирование»    | да   | при dirty draft |
| view (чужой) | «Просмотр карточки» | нет  | не требуется    |

### Зависимости

| Слой                   | Зависимости                                                     |
| ---------------------- | --------------------------------------------------------------- |
| entities/card          | `CardSearchService`, `CardCatalogSearchStore`, `CardIndexEntry` |
| entities/language-pair | `UserStore.languagePair()`                                      |
| features/card-editor   | `CardEditorDialogService`, `CardEditorStore`                    |
